┌─ WHAT IT TESTS ───────────────────────────────────────────────────────────────┐
│                                                                                │
│  📊 STRONG SCALABILITY                                                        │
│     Fixed problem, varying workers                                            │
│     Sizes: 100, 400, 900, 1600 pixels                                         │
│     Workers: 1, 2, 4, 6, 8                                                    │
│     Ideal: Linear speedup (2x workers = 2x faster)                            │
│                                                                                │
│  📈 WEAK SCALABILITY                                                          │
│     Problem scales with workers                                               │
│     Base: 100 pixels per worker                                               │
│     Ideal: Constant execution time                                            │
│                                                                                │
└────────────────────────────────────────────────────────────────────────────────┘

┌─ METRICS ─────────────────────────────────────────────────────────────────────┐
│                                                                                │
│  ⏱️  Execution Time: How long to process all pixels                           │
│                                                                                │
│  🚀 Speedup = Sequential Time / Parallel Time                                 │
│     Example: 10s seq, 2s parallel = 5.0x speedup                              │
│                                                                                │
│  ⚡ Efficiency = Speedup / Number of Workers                                   │
│     Example: 5x speedup, 8 workers = 62.5% efficiency                         │
│                                                                                │
└────────────────────────────────────────────────────────────────────────────────┘

┌─ CUSTOMIZATION ───────────────────────────────────────────────────────────────┐
